Technical details

TENET has enforced nothing yet

TENET sits between an AI agent and the tools it wants to use. Before any tool runs it checks identity, entitlement, warrant and policy, reaches a verdict, and writes a receipt. Nothing executes until that verdict allows it, and a denied action never reaches the far side of the boundary.

To put the first real action on this screen:

  1. Point TENET at a live tool server (the WARRNT_UPSTREAM environment variable) so a real crossing is possible.
  2. Press Run the paired allow / deny scenario below: the same request is made by two agents and the kernel reaches two different verdicts.
  3. Or let a real agent call the control plane and watch its own action appear here.
