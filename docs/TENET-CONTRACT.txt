THE BOUNDARY OBJECT (this is what "datastream" means here)
----------------------------------------------------------
Not "market data". The object TENET must see and control on the request path is:

  identity → agent → tenant/team → run_id/action_id → prompt/input → model/provider
  → tool name → tool arguments → policy/profile → decision → execution → response
  → usage/cost/latency → receipt

Cloudflare, LiteLLM, Purview and Zscaler inspect this object at the boundary;
LangSmith/Langfuse additionally correlate model calls, tool invocations and retrieval
in one trace. TENET must sit on that path and decide BEFORE egress.
Goldman Sachs (Marquee / GS Quant) is the target enterprise archetype, NOT a claimed
integration. The honest line is: "the same control architecture can govern an entitled
enterprise connector such as GS Marquee."
